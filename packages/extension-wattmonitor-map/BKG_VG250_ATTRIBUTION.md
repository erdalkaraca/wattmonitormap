# BKG VG250 Attribution

The municipality and state boundary assets generated by this package are derived
from the BKG product "Verwaltungsgebiete 1:250 000, Stand 31.12. (VG250 31.12.)".

Source dataset:
- Provider: Bundesamt fuer Kartographie und Geodaesie (BKG)
- Product page: https://gdz.bkg.bund.de/index.php/default/digitale-geodaten/verwaltungsgebiete/verwaltungsgebiete-1-250-000-stand-31-12-vg250-31-12.html
- Download base used by the generator script: https://daten.gdz.bkg.bund.de/produkte/vg/vg250_ebenen_1231/aktuell/

License:
- Datenlizenz Deutschland - Namensnennung - Version 2.0
- License text: https://www.govdata.de/dl-de/by-2-0

The generated GeoJSON files are modified derivatives because the build process
reprojects, filters, splits, and simplifies the original geometries.

Recommended attribution for this repository and downstream web use:

> Copyright BKG 2026, dl-de/by-2-0, data modified; source: VG250 31.12,
> https://sgx.geodatenzentrum.de/web_public/gdz/datenquellen/datenquellen_vg_nuts.pdf

Notes from the BKG product page:
- Attribution is required for public display, distribution, presentation, and external use of derived works.
- For web use, "BKG" should link to https://www.bkg.bund.de and "dl-de/by-2-0" should link to https://www.govdata.de/dl-de/by-2-0.
- If the data is changed, that must be indicated in the attribution.

If the dataset is refreshed in a later year, update the attribution year to the
year of the latest data retrieval.
